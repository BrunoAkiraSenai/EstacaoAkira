#  EstacaoAkira

Aplicativo mobile desenvolvido com React Native e Expo para monitoramento climático, exibição de previsões do tempo e organização de informações meteorológicas através de integração com APIs.

---

##  Sobre o Projeto

O **EstacaoAkira** foi criado com o objetivo de praticar desenvolvimento mobile, integração com APIs REST e visualização de dados climáticos em uma interface moderna e intuitiva.

O projeto utiliza React Native com Expo e possui múltiplas telas, dashboards e funcionalidades voltadas para consulta e organização de informações meteorológicas.

---

## 🚀 Tecnologias Utilizadas

- React Native
- Expo
- JavaScript
- Axios
- React Navigation
- Async Storage
- APIs REST
- Victory Charts
- Recharts
- Git & GitHub

---

##  Funcionalidades

- 📍 Consulta de clima e previsão do tempo
- 📊 Dashboards climáticos
- 📅 Calendário meteorológico
- 🔐 Sistema de navegação entre telas
- 💾 Armazenamento local de dados
- 📈 Exibição gráfica de informações
- 📱 Interface mobile responsiva
